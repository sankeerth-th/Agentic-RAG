## Implementation plan

Use Superpowers planning, test-driven development, verification and review, with
Ponytail FULL. The M0 assignment already selects the architecture; this is its
bounded implementation plan, not a replacement architecture proposal.

1. Add uv workspace members `apps/api`, `packages/contracts`, `workers/ingestion`
   and one shared Python 3.12 environment. Pin resolved dependencies in uv.lock.
   Add pnpm solely for generated TypeScript contracts, with a lockfile.
2. Write contract rejection/round-trip tests in `tests/contract/` first: empty or
   duplicate version scopes, missing provenance, invalid limits, non-finite metrics,
   unknown cost, versioned model configuration and bounded agent execution.
   Implement canonical schemas in `packages/contracts/src/rag_contracts/`.
3. Write health/readiness/error tests in `tests/unit/` first. Implement
   `apps/api/app/core/{config,services,errors,logging}.py` and `main.py`.
   Liveness stays available during dependency failures; readiness returns 503 if
   PostgreSQL/migration, Qdrant, Redis or the configured S3 bucket fails.
   Errors/logs expose stable codes and request IDs, not credentials or raw payloads.
4. Write PostgreSQL integration cases in `tests/integration/` first: migration
   upgrade/downgrade, immutable snapshots, unique versions, valid cross-entity
   provenance and trace ordering. Implement SQLAlchemy tables in
   `apps/api/app/core/models.py`, DB setup and a reviewed Alembic baseline.
   Snapshot data cannot be updated or deleted; jobs/runs carry mutable state.
5. Add bounded service clients and S3 stream operations, local Compose with
   loopback ports/named volumes/health checks, and Celery ingestion worker startup.
   Smoke test real PostgreSQL, Qdrant, Redis, S3 round-trip and worker ping.
6. Export deterministic OpenAPI from the actual app, including reusable domain
   components without invented routes. Generate TypeScript using openapi-typescript.
   Contract CI regenerates both artifacts and rejects drift; TypeScript compiles.
7. Add CI for Ruff, mypy, pytest, contracts and a real Compose service/migration
   smoke test. Document fresh setup and exact commands in CONTRIBUTING.md/README.md.
8. Fetch/synchronize main, run Graphify over the current state, inspect module
   boundaries and ownership, run all checks, review the complete diff and simplify
   with Ponytail. Push the S01 branch and open its PR. Require the actual CI checks
   on main. Record independent review pending; do not merge.

For each behavioral step run the relevant pytest command and observe failure
before implementation, then rerun to green. The final commands are:
`uv run ruff check .`, `uv run ruff format --check .`, `uv run mypy`,
`uv run pytest tests/unit tests/contract`, `pnpm contracts:check`,
`uv run pytest tests/integration` with documented local services available.

## Acceptance evidence

S01 requires reproducible setup, successful package builds, health/readiness,
migration round-trip, real client connections, safe errors/logs, validated shared
schemas, reproducible Python/OpenAPI/TypeScript contracts, passing CI and Graphify,
and no implementation in Vishnu-owned directories. The PR records measured results
and unresolved blockers. Independent human review remains separate from technical
self-review or an agent review.
